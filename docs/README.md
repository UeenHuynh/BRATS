# Chỉ mục tài liệu

Đọc theo luồng sau:

1. [`../README_WORKSPACE.md`](../README_WORKSPACE.md) — bản đồ workspace và nguồn có thẩm quyền.
2. [`DATA_PROVENANCE.md`](DATA_PROVENANCE.md) — archive, checksum, canonical view và patch 0402.
3. [`INCIDENT_0402.md`](INCIDENT_0402.md) — bằng chứng lỗi, nguyên nhân và phạm vi ảnh hưởng.
4. [`VALIDATION_AND_RERUN.md`](VALIDATION_AND_RERUN.md) — data gates, quyết định chạy lại và lệnh kiểm tra.
5. [`EXPERIMENT_RESULTS.md`](EXPERIMENT_RESULTS.md) — kết quả cũ/mới, điều gì so sánh được và chưa được.
6. [`RERUN_READINESS.md`](RERUN_READINESS.md) — gate nào đã pass, job nào đang chạy và khi nào được training.
7. [`ABLATION_PROTOCOL.md`](ABLATION_PROTOCOL.md) — protocol 5 nhánh, lệnh submit và lệnh tự kiểm tra trên `ydang`.

Các file `planning/` và `reports/` ở root là tài liệu lịch sử của pipeline cũ. Chúng hữu ích để audit nhưng không thay thế các quyết định canonical ở đây.

- [`../planning/README.md`](../planning/README.md): trạng thái của các kế hoạch cũ.
- [`../reports/README.md`](../reports/README.md): report nào bị ảnh hưởng, report nào chỉ là scaffold.
